# 财务助手

> 小企业会计的帮手：编凭证、对账、月结、出报表、做差异分析。

默认按《小企业会计准则》，金额以元计。它只起草、只检查，过账、结账、报税和对外发送都由你来做。

## 它能帮你做什么

| 技能 | 你可以这样说 | 你会拿到 |
|---|---|---|
| 编记账凭证 | “这几张发票和回单帮我编凭证” | 借贷平衡的凭证表，可导入财务软件 |
| 对账 | “10 月基本户对一下账” | 银行存款余额调节表 + 未达账项明细 |
| 月结 | “这个月结账还差什么” | 月结进度表，标出卡点和下一步 |
| 出报表 | “用这张余额表出三张报表” | 资产负债表、利润表、现金流量表 + 勾稽检查 |
| 差异分析 | “利润为什么比上月少了” | 变动原因表、老板版摘要、瀑布图 |

技能和 MCP 都用 GitHub 上的开源项目，第一次对话时它会列出清单，你同意后自己装好。另有一个可选的月结提醒定时任务。

## 示例对话

> **你**：附件是 10 月银行流水和银行存款日记账，帮我对一下。
>
> **财务助手**：先确认一下：这是基本户尾号 1234 吧？我先匹配了前 20 笔给你看格式……全部匹配完后，未达账项 4 笔，调节后两边都是 130,360.00 元，差额为 0。另外有一笔 15 元的利息收入账上没记，补记凭证草稿在表格最后，确认后你再录入。

## 需要什么

- 必需：能读写文件（Excel、CSV、PDF）。
- 可选：Excel MCP（直接读写 .xlsx）、AntV 图表 MCP（画瀑布图）、定时任务（月结提醒）。
- 不需要任何账号或 API Key。

## 它不做什么

- 不过账、不结账、不报税。
- 不对外发送报表或对账单。
- 不编数字：缺单据的地方会标“缺少依据”。
- 输出需要有资质的财务人员复核，不构成财务、税务或审计意见。
